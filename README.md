# VisualGCDLCM

以切割長方形的方式，視覺化理解最大公因數（GCD）。

## 功能

- 電腦自動產生可求得最大公因數的長、寬題目。
- 每題提供三個數字選項。
- 第一關「選邊長」練習判斷最大正方形邊長。
- 第一關答對後才出現第二關「選正方形總數」。
- 第二關使用「長邊塊數 × 寬邊塊數」作答。
- 以俯視切割動畫顯示完整方格與剩餘區域。
- 答對時播放慶祝音效，並顯示彩帶與縮放動畫。
- 以「最大公因數」下拉選單切換三個例子：正方形切割、相同物品平均分裝、場地等距設柱。
- 場地等距設柱採兩關線性作答：先選最大柱距，再選四周柱子總數，並提供即時正誤提示與完成慶祝效果。
- 物品平均分裝採兩關線性作答：先選最多包數，再選每包的兩種物品數量；設柱總數以三組「兩數相乘」選項作答。
- 支援桌面與手機版面。

## 使用方式

直接以瀏覽器開啟 `index.html`。
